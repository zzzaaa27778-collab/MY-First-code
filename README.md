# Price Monitor Script

A Python script that monitors product prices on e-commerce websites and sends desktop notifications when prices drop below a specified target.

## Features
- Scrapes product pages to get the latest price.
- Compares current price with target price.
- Sends instant desktop alert notifications.

سكريبت بايثون لمراقبة أسعار المنتجات على مواقع التسوق، ويقوم بإرسال إشعارات على سطح المكتب عندما ينخفض السعر عن الحد المطلوب.
